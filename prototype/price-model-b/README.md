# Fluxfield · price diffusion sandbox

Open `index.html` directly in a browser. The simulation and controls are local; no install, server or build is required.

Run the model tests from this directory with `node --test simulation.test.js`. Designs: `archive/01-price-model-b-plan.md`, `archive/02-gold-money-plan.md`, `archive/04-profit-towns-plan.md`; future work in `03-faction-money-plan.md`.
