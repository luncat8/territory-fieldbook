# Fluxfield · Price Model B2 (carried worker money)

Open `index.html` directly in a browser. The simulation and controls are local; no install, server or build is required.

Files: `simulation.js` (fields, diffusion, cost-basis transport, paid/free wood & food flows and proportional worker-gold advection), `actors.js` (universal firm pricing, fresh-worker pools, firm scale), `farms.js` (forest-patch sawmills and cultivated-plot seasonal farms), `towns.js` (housing rooms, wait pools, living tax, paid rest, gold-backed wood/food bids and the three town wealth-class strategies), `gold.js` (conserved vaults, resident purses, worker wallets and payment streams), `workforce.js` (self-moving resident workers, split/starvation lifecycle, wallet-weighted home appeal and shelter), `land.js` (terrain build ladder, moisture, water, wasteland, consumption litter/CO2, claims and site quality), `settlement.js` (forest, non-teleporting young-town founding and tiers), `harvest.js` (town wild food/wood foraging fallback and food/wood consumption), `fields.js` (dual map renderer), `telemetry.js` (sparklines and ledgers) and `app.js` (UI).

Run the model tests from this directory with `node --test`. Design & worklogs: `archive/06-worker-money-b2-plan.md`, `archive/07-worker-pools-b2-plan.md`, `archive/08-workforce-settlements-b2-worklog.md`, `archive/09-town-wealth-class-b2-worklog.md`, `archive/10-land-town-spawn-b2-worklog.md`, `archive/11-land-harvest-b2-worklog.md`, `archive/12-resident-workers-farms-sawmills-b2-worklog.md`, `archive/13-review-resident-workers-b2-worklog.md`, `archive/14-map-wrap-torus-b2-worklog.md`.

`workforce.js` and `land.js` read only shared fields (`priceHome`, `priceRest`, wallets, terrain, actors) so a particle engine can reuse them per carrier; see `draft/particle_transfer_model.md`.
