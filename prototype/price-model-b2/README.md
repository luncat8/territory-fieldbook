# Fluxfield · Price Model B2 (carried worker money)

Open `index.html` directly in a browser. The simulation and controls are local; no install, server or build is required.

Files: `simulation.js` (fields, diffusion, cost-basis transport and proportional worker-gold advection), `actors.js` (universal firm/town pricing, gold-tax appeal and paid worker rest), `gold.js` (conserved vaults, resident purses, worker wallets and payment streams), `fields.js` (dual map renderer), `telemetry.js` (sparklines and ledgers) and `app.js` (UI).

Run the model tests from this directory with `node --test`. Design & worklogs: `archive/06-worker-money-b2-plan.md`, `archive/07-worker-pools-b2-plan.md`.
